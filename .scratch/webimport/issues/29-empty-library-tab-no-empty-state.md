# 29: Empty Library tab has no empty state (unlike Undo tab)

Status: ready-for-agent

**Category:** enhancement
**Source:** UX walkthrough session (Playwright MCP, browser-driven, per
ADR-0009). Reporter-suggested severity: Low.

## What was observed

An empty Library tab shows nothing but the heading and search box — no
message. The Undo tab, by contrast, already has a proper empty state
("Nothing pending undo."). The Library tab should match that pattern.

## Agent Brief

**Category:** enhancement
**Summary:** Add empty state messaging to the Library tab when the library is empty, interpolating the search query when filtering yields no results

**Current behavior:**
When the library has no albums (or when a search query yields zero matches), the Library view displays a blank area with no message or indication, unlike the Undo tab which displays "Nothing pending undo." On successive searches with no results, it is unclear whether a new search executed or the server failed to respond.

**Desired behavior:**
1. When the library is empty on initial load, display a clean empty state message (e.g. `<p class="muted">No albums in library.</p>`).
2. When a search filter is active and matches nothing, display an explicit search empty state interpolating the exact search query (e.g. `<p class="muted">No albums matching &ldquo;{query}&rdquo; found.</p>`), providing immediate visual confirmation that the specific search was performed.

**Key interfaces:**
- `app.js` (`loadLibrary` / `renderAlbums`).
- `style.css` (`.empty-state` / `.muted` styling).

**Acceptance criteria:**
- [ ] Navigating to the Library tab with an empty database shows a "No albums in library." message.
- [ ] Typing a query that matches no albums shows a "No albums matching “<query>” found." message including the exact string typed.
- [ ] Changing the search query dynamically updates the quoted search string in the empty state message.
- [ ] When albums exist and match, the empty state is hidden and the album grid renders normally.

**Out of scope:**
- Adding import buttons or promotional cards inside the empty state.
