# 26: No double-submit protection — same inbox path listed under both Inbox and Pending Review at once

Status: ready-for-agent

**Category:** bug
**Source:** UX walkthrough session (Playwright MCP, browser-driven, per
ADR-0009). Reporter-suggested severity: Medium.

## What was observed

After clicking "Start import" on a folder, that same folder appears
simultaneously under both the "Inbox" section (with its own enabled
"Start import" button) and the "Pending review" section. Nothing prevents
clicking "Start import" a second time on the same folder while its first
review is still in flight.

## Why it matters

A second "Start import" for the same folder likely creates a second,
independent Import Task (see `CONTEXT.md`'s Import Task/Import Session
entries) for files already mid-review — worth confirming during triage
whether this can itself lead to a duplicate-album outcome similar to
finding #22, or a confusing pair of review queues for the same files.

## Evidence

- `.playwright-mcp/01-after-start-import.png` — the Mulan folder visible
  under both "Inbox" (enabled "Start import" button) and "Pending review"
  simultaneously.

## Reproduction

1. Click "Start import" on any inbox folder.
2. Without waiting for review to complete, check both the "Inbox" and
   "Pending review" sections — the same folder/path appears in both, and
   the Inbox's "Start import" button for it remains clickable.

## Agent Brief

**Category:** bug
**Summary:** Prototype both duplicate submission prevention options (omitting from unsubmitted list vs disabled badge), prompt user to pick, and implement choice

**Current behavior:**
When "Start import" is clicked for an inbox directory, that directory remains listed in the unsubmitted Inbox list with an active "Start import" button even while it is concurrently displayed in the Pending Review section. Clicking the button again submits a second redundant Import Task for the same folder.

**Desired behavior:**
1. Prototype both UI prevention strategies:
   - **Option A (Omit from inbox list):** While a directory is in-flight or pending review, it is removed from the unsubmitted "Inbox" list and only appears under "Pending review". Once finished, it returns (or is removed).
   - **Option B (Disable with status badge):** The directory remains in the "Inbox" list, but its "Start import" button is replaced with a disabled `[In Progress]` / `[Pending Review]` badge.
2. Present both prototypes to the user for selection.
3. Fully implement and verify the chosen option.

**Key interfaces:**
- `server.py` (`/api/inbox` endpoint returning active/pending states or filtered unsubmitted paths).
- `app.js` (`renderInbox` UI logic).

**Acceptance criteria:**
- [ ] Both Option A and Option B prototypes are presented to the user for a decision.
- [ ] The chosen option is implemented cleanly.
- [ ] An inbox folder currently in-flight or pending review cannot have "Start import" clicked a second time.
- [ ] If an in-flight import is completed or skipped/canceled, the inbox list updates its status accordingly.

**Out of scope:**
- Detection of whether source files in the inbox match albums already present in the library database (covered separately in #22).
