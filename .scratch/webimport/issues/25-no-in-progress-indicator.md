# 25: "Awaiting candidate review" has no in-progress indicator during lookup

Status: done

**Category:** enhancement
**Source:** UX walkthrough session (Playwright MCP, browser-driven, per
ADR-0009). Reporter-suggested severity: Medium.

## What was observed

After clicking "Start import," the resulting "Awaiting candidate review"
state has no spinner or other animation while the MusicBrainz/chroma
lookup is in progress. It reads as frozen rather than actively working.

## Why it matters

Minor on its own, but compounds with finding #23 (no apply feedback) to
make the whole review flow feel unresponsive/uncertain about what state
it's in.

## Evidence

- `.playwright-mcp/01-after-start-import.png` — the static "Awaiting
  candidate review" state, immediately after clicking "Start import."

## Reproduction

1. Click "Start import" on any inbox folder.
2. Observe the "Awaiting candidate review" state while the lookup runs —
   no visual indication of progress.

## Comments

> *This was generated by AI during triage.*

## Agent Brief

**Category:** enhancement
**Summary:** Add progress/completion indicator to pending review items during candidate lookup, showing percentage/request progress if introspectable

**Current behavior:**
When an inbox folder is submitted for import, the Pending Review card renders static text ("Awaiting candidate review") with no visual animation, percentage, or progress indicator while the backend worker searches MusicBrainz / fingerprint sources.

**Desired behavior:**
1. Introspect what beets' candidate lookup and match plugins expose during candidate search (e.g. stage events, plugin queries, or number of candidate sources being queried).
2. If progress steps or request counts can be tracked from the backend, expose this progress via API/polling and display a percentage or progress counter (e.g. "Searching candidates (2/5 sources queried)..." or "60% complete") in the Pending Review card.
3. If granular sub-query introspection is not supported by beets' synchronous lookup pipeline, display an active animated spinner with clear descriptive status ("Searching MusicBrainz & fingerprint sources...").

**Key interfaces:**
- `session.py` / `server.py` (`WebImportSession` tracking lookup progress or pending review state).
- `app.js` (`renderInbox` pending review card rendering).
- `style.css` (progress bar / spinner styling).

**Acceptance criteria:**
- [x] The agent investigates beets candidate lookup introspection capabilities and documents the findings.
- [x] If request/lookup step counts are introspectable, the Pending Review card shows a percentage or step count progress bar.
- [x] If step counts are not introspectable, an animated spinner with active status text is displayed.
- [x] When candidate lookup finishes and the review decision is ready, the progress indicator transitions to the actionable "Review" button.

**Out of scope:**
- Modifying upstream beets plugin lookup algorithms.
