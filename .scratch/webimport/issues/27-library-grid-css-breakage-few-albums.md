# 27: Library grid tile CSS breaks visually while art is loading/missing, especially with few albums

Status: done

**Category:** bug
**Source:** UX walkthrough session (Playwright MCP, browser-driven, per
ADR-0009). Reporter-suggested severity: Medium.

## What was observed

In `static/style.css`, the `.grid`/`.album-tile` rules use
`grid-template-columns: repeat(auto-fill, minmax(140px, 1fr))`, which lets
a single tile stretch to fill the row when there are only 1-2 albums.
Combined with `aspect-ratio: 1` on the `<img>`, a tile whose art hasn't
loaded yet (or is missing) blows up to near-full-viewport height, because
the `onerror` handler only sets `visibility: hidden` — which still reserves
the full aspect-ratio box rather than collapsing it.

This is specifically a broken/loading-state bug, not a steady-state grid
layout problem: once art finishes loading, the same tile renders correctly
sized (see the "after" evidence below).

## Reproduction

1. Import a single album into an otherwise-empty or near-empty library.
2. View the Library tab immediately, before art has finished
   loading/embedding.
3. Observe the oversized tile; compare against a reload once art has
   loaded, which renders correctly.

## Agent Brief

**Category:** bug
**Summary:** Fix library grid CSS blowout when libraries have 1-2 albums or when cover art is loading/missing

**Current behavior:**
In `style.css`, `.grid` uses `grid-template-columns: repeat(auto-fill, minmax(140px, 1fr))`, allowing single/few album tiles to stretch across the full container width. Combined with `aspect-ratio: 1` on `.album-tile img` and `onerror` hiding visibility rather than maintaining layout bounds, a missing or loading image expands the tile into an oversized viewport-height empty block.

**Desired behavior:**
1. Album tiles in the library grid have a bounded maximum column width or max-width (e.g. 180-220px) rather than infinitely expanding to 1fr on sparse rows.
2. When cover art is loading or fails to load, a styled, fixed-dimension placeholder (e.g. vinyl/disc icon or neutral placeholder box) is displayed instead of a blown-up invisible image box.

**Key interfaces:**
- `style.css` (`.grid`, `.album-tile`, `.album-tile img`, `.album-tile .placeholder`).
- `app.js` (`renderAlbums` tile image error handling).

**Acceptance criteria:**
- [x] A library containing a single album renders a normally-sized tile (not stretched across the full screen width/height).
- [x] Albums with missing/404 art render a compact placeholder with title/artist text intact.
- [x] Responsive behavior on mobile and desktop viewports is preserved.

**Out of scope:**
- Implementing the server-side thumbnail caching layer (handled in #17).
